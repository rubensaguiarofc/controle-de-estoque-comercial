## 🎯 Funcionalidades para Testar

### 1. Biblioteca de Itens
- Acesse o menu lateral → "Biblioteca de Itens"
- Teste adicionar um novo item
- Teste editar e excluir itens
- Teste a busca de itens

### 2. Entrada de Estoque
- No menu principal, acesse "Entrada de Estoque"
- Use o scanner de código de barras (botão de câmera)
- Ou pesquise manualmente um item
- Adicione quantidades e teste o atalho Enter
- Observe os indicadores de estoque

### 3. Saída de Estoque
- Acesse "Saída de Estoque"
- Selecione itens e registre retiradas
- Veja o estoque sendo atualizado automaticamente

### 4. Ferramentas
- Acesse "Ferramentas" no menu
- Adicione uma nova ferramenta
- Faça o checkout (emprestar ferramenta)
- Faça o return (devolver ferramenta)

### 5. Relatórios e Dashboard
- Veja o dashboard com gráficos e estatísticas
- Acesse o histórico de movimentações
- Exporte relatórios se necessário

### 6. Sistema de Backup
- Menu → Configurações → Backup
- Teste exportar backup
- Teste restaurar backup
- Verifique a validação SHA-256

### 7. Anúncios
- Observe os banners AdMob nas telas
- Teste a exibição de anúncios intersticiais após algumas ações
- Teste vídeos de recompensa (se disponível)
